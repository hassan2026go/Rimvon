# Rimvon

مراسلة ومكالمات خاصة ومشفّرة بنمط Zangi، باستضافة ذاتية (بدون GitHub/Firebase/Google).

```
server/    خادم Node.js (حسابات + مرحّل مشفّر + إشارات المكالمات + صفحة تحميل الـ APK)
android/   تطبيق أندرويد (Kotlin + Jetpack Compose + WebRTC)
deploy/    ملفات الإعداد: Caddy، systemd، coturn، متغيرات البيئة
design/    الأيقونة (SVG/PNG) وسكربت توليد أيقونات أندرويد
DEPLOY.md  دليل الاستضافة والتثبيت خطوة بخطوة
```

الحالة: الخادم مُختبر بسكربت آلي (`cd server && npm install && npm test`). تطبيق أندرويد مكتوب ومُراجع يدوياً ولم يُبنَ بعد على جهاز، فتوقّع احتمال أخطاء بناء صغيرة عند أول تشغيل.
